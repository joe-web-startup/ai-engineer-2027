# Week 1 · Day 5 — Git, GitHub et qualité du code

## Au programme
- Les trois zones de Git, `add`, `commit`, `log`, les branches, `push` vers GitHub, revenir en arrière.
- `.gitignore`, messages de commit clairs, secrets à ne jamais publier.
- Code lisible (PEP 8, noms explicites, fonctions courtes, docstrings), README en 6 sections.
- Tests avec `assert` et `pytest` : cas normaux, limites, vides, invalides.
