# Week 1 · Day 2 — Les bases de Python, fichiers et erreurs

## Ce que j'ai appris
- La routine de travail dans VS Code : écrire, enregistrer, lancer (`py fichier.py`), lire le résultat.
- Les variables, les 4 types (`int`, `float`, `str`, `bool`) et les conversions (`int("25")`).
- Lire un message d'erreur de bas en haut : type, explication, ligne.
- Décider avec `if` / `elif` / `else`, répéter avec `for` / `while`.
- Les listes, les fonctions, et la différence entre `return` et `print`.
- Lire et écrire des fichiers, gérer les erreurs avec `try` / `except`, organiser le code en modules.
