# Week 1 · Day 3 — Fonctions, fichiers, JSON et erreurs

## Ce que j'ai appris
- `def` fabrique une fonction, `return` donne le résultat et l'arrête ; sans `return`, la fonction renvoie `None`.
- Enchaîner plusieurs fonctions comme un pipeline : la sortie de l'une est l'entrée de la suivante.
- Lire et écrire des fichiers avec `with open`, les modes `r` / `w` / `a`, nettoyer avec `strip` et `split`.
- Sauvegarder et relire des données en JSON (`json.dump`, `json.load`).
- Gérer les erreurs avec `try` / `except` : `ValueError`, `TypeError`, `FileNotFoundError`, et `raise`.

## Ce que j'ai fait
- Révisions `r1` à `r4` : `=` ou `==`, `if` / `elif` / `else`, compter avec `c = c + 1`, `def` + `return` testé par `assert`.
- Exercices express et mini-projet « analyseur de notes » (`exercices/projet`).
