# Week 1 · Day 4 — Terminal, Linux et environnement de développement

## Au programme
- Se déplacer et travailler sans souris : `pwd`, `ls`, `cd`, chemins relatifs et absolus.
- Créer, copier, déplacer, supprimer : `mkdir`, `cp`, `mv`, `rm`.
- Chercher et enchaîner : `find`, `grep`, `|`, `>`, et un premier script Bash.
- Environnement Python professionnel : `venv`, `pip`, `requirements.txt`, `sys.argv`, `pathlib`.
