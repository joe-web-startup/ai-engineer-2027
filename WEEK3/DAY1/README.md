# Week 3 · Day 1 — Les stats et les maths du Machine Learning

## Ce que j'ai appris
- **Moyenne** : le partage équitable. **Médiane** : l'élève du milieu, qui résiste aux valeurs bizarres (un 0, un absent).
- **Écart-type** : les valeurs sont-elles serrées ou éparpillées autour de la moyenne ?
- **Corrélation** (de −1 à +1) : deux colonnes bougent-elles ensemble ? Ce n'est pas une preuve de cause.
- **Vecteur** = une ligne de nombres (un élève). **Matrice** = le tableau entier. **X** = ce qu'on donne au modèle, **y** = ce qu'il doit deviner.
- Le réflexe avant d'entraîner un modèle : `df.describe()` et `df.corr()`.
