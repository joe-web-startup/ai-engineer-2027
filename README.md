# AI Engineer 2027 · Journal d'apprentissage

Je me forme au métier d'**AI/ML Engineer** et j'apprends en public : chaque jour, un cours, des exercices et une avancée sur mon produit, **[ExamPredict AI](https://github.com/)** *(lien à mettre à jour)*.

## Méthode
1. **Cours** : une fiche par notion (`cours/WEEK<n>/F<n>.DAY<n>.WEEK<n>.pdf`).
2. **Pratique** : de petits exercices, puis leur application au produit.
3. **Expliquer à voix haute** : chaque notion devient une courte vidéo « AI ML Éducation ».

## Progression

| Semaine | Jour | Thème | Fiches | Exercices |
|---|---|---|---|---|
| 1 | Day 1 | Modèle mémoire Python, structures de données, conception d'ExamPredict | F1, F2, F3 | `exercices/jour1` |
| 1 | Day 2 | Les bases de Python : variables, types, conditions, boucles, listes, fonctions | F1 | `exercices/jour2` |

## Structure
```
cours/        fiches de cours (PDF)
exercices/    exercices, rangés par jour
week-0/       préparation
```

## Lancer un exercice
```bash
py exercices/jour2/ex06_fonctions.py
```
